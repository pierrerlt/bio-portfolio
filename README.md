<h2>🌐 Bio Portfolio (React + TypeScript)</h2>

<p>
A modern and animated <strong>personal portfolio website</strong> built with
<strong>React</strong> and <strong>TypeScript</strong>.
It features smooth intro animations, interactive cursor effects,
and clean section-based navigation.
</p>

<img src="assets/preview.png" alt="Portfolio Preview" width="100%" />

<h3>✨ Features</h3>
<ul>
  <li>Modern React + TypeScript setup</li>
  <li>Animated intro overlay</li>
  <li>Interactive cursor particle effect (Canvas)</li>
  <li>Smooth page reveal animations</li>
  <li>Responsive layout</li>
  <li>Sections: Hero, About Me, Timeline, Projects, Contact</li>
</ul>

<h3>🚀 Getting Started</h3>

<p>Follow these steps to run the project locally:</p>

<ol>
  <li><strong>Clone the repository</strong></li>
</ol>

<pre>
git clone https://github.com/pierrerlt/bio-portfolio.git
cd bio-portfolio
</pre>

<ol start="2">
  <li><strong>Install dependencies</strong></li>
</ol>

<pre>
npm install
</pre>

<ol start="3">
  <li><strong>Start the development server</strong></li>
</ol>

<pre>
npm start
</pre>

<p>
The app will run at <strong>http://localhost:3000</strong>
</p>

<h3>🏗️ Build for Production</h3>

<pre>
npm run build
</pre>
